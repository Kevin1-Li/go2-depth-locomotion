## 1. 最终 Student 架构（LSTM + Patch Cross-Attention）

- 深度输入 **32×48**（RayCasterCamera，非 64×64 CNN）
- 4×4 patch tokenization → 96 tokens × 16-dim + 可学习位置编码（8×12）→ K/V
- 当前本体（45 维）→ 1 个 Query token；**21 帧本体历史 → LSTM(128)** → h_t
- Fusion MLP([h_t; c_t]) → z_s（128 维，对齐 Teacher 特权 latent z_t）
- Actor([z_s, x_t]=173 → 12)
- **双损失蒸馏**：λ_repr=1.0（latent MSE）+ λ_action=1.0（action MSE），Teacher 冻结
- 参数量 376,728；推理延迟 ~0.6-1ms（50Hz 控制周期余量 20 倍）
- 代码：`code/source/unitree_rl_lab/unitree_rl_lab/models/depth_student.py`（fusion_type="lstm_patch_ca"）

## 3. 键盘手动驾驶模式（新增）

```bash
cd unitree_rl_lab
~/IsaacLab/_isaac_sim/python.sh scripts/rsl_rl/play_standalone.py --model student --keyboard
# 可选：--speed_scale 1.5（超出训练指令范围实验，跟踪会变差）
# 换模型：--model teacher / --model blind
```

- 单狗 + 实时速度；**按住走、松开停**（按住 ~0.4s 爬到巡航，松开按减速度归零；靠终端按键自动重复推断"按住"状态，焦点须留在终端）
- W/S 前后（巡航 ±1.0 m/s）· A/D 转向（±1.0 rad/s）· Q/E 横移（±0.4）· 空格急刹
- keyboard 模式自动：num_envs=1、real_time、冻结指令重采样/heading/standing、**禁用 20s episode 截断**（不再每 20 秒重生回出生点）
- 实测特性：策略对 |yaw|<~0.3 rad/s 有转向死区（训练分布所致），巡航 1.0 rad/s 转向干脆；训练指令范围 vx ±1.0 / vy ±0.4 / yaw ±1.0（课程从 ±0.1 爬升），实际极速 ~0.9 m/s
- 每 100 步打印 `cmd vs actual`（vx/vy/yaw_rate/heading）遥测对照
- 摔倒仍会自动重生（terminations 保留）
